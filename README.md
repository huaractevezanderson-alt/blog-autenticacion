# Blog con Autenticación Básica

## Descripción

Aplicación web tipo blog desarrollada con HTML, CSS y JavaScript.

Incluye:

- Registro de usuarios
- Inicio de sesión
- Cierre de sesión
- CRUD de publicaciones
- Persistencia con LocalStorage
- Vista individual de publicaciones

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

### Autenticación

- Registro
- Login
- Logout

### Blog

- Crear publicaciones
- Editar publicaciones
- Eliminar publicaciones
- Ver publicaciones

## Despliegue

Proyecto publicado con GitHub Pages.
